# Прокрутка длинных меню выбора

## Цель

Во всех меню выбора на базе общего RMC-диалога варианты должны оставаться доступными на небольших разрешениях и при длинных списках. Пользователь должен прокручивать только область вариантов, не теряя заголовок, описание и поле поиска.

## Дизайн

Изменение выполняется в общем клиентском контейнере `RMCDialogOptionsContainer`, который используется `DialogBui` для `DialogType.Options`. Серверный список `DialogOption`, порядок вариантов, индексы сообщений и обработчики выбора остаются без изменений.

Область `Options` размещается внутри вертикально прокручиваемого `ScrollContainer` с ограниченной высотой. При переполнении появляется вертикальная полоса прокрутки; поле поиска остаётся ниже списка и продолжает фильтровать существующие кнопки. Остальные типы диалогов (`Input`, `Confirm`) не меняются.

## Критерии готовности

- Длинный список вариантов не выходит за пределы окна.
- Все варианты доступны колесом мыши и полосой прокрутки.
- Заголовок, сообщение и поиск остаются видимыми.
- Выбор пункта отправляет тот же индекс, что и до изменения.
- Клиент и сервер собираются без ошибок.
