## Сборка

### Служебный BuildChecker: MSB3822 / MSB3823

Ошибки воспроизведены отдельно в `BuildChecker.csproj`: стандартные SDK-маски
подхватывали `.resx` из `BuildChecker/RobustToolbox`. После исключения ресурсов
обнаружился тот же ошибочный захват исходников C# из этой вложенной копии.
Служебный проект теперь исключает автоматический сбор обоих типов файлов;
`Compile` и `EmbeddedResource` при вычислении MSBuild пусты. Новые зависимости
`System.Resources.Extensions` и настройка предварительной сериализации не нужны.

Причина появления вложенной копии также исправлена: помощник подмодулей задаёт
корень репозитория явно, даже при унаследованном от hook `GIT_DIR`, относительном
`GIT_WORK_TREE` и вызове из `BuildChecker`. Маркер отключения читается рядом со скриптом.

Проверки:

* `dotnet build BuildChecker/BuildChecker.csproj --no-restore -t:Rebuild`:
  **0 ошибок, 0 предупреждений**.
* `py -3 -m unittest discover -s BuildChecker -p test_git_helper.py -v`:
  **4/4 прошли** — обычный checkout, linked worktree, маркер отключения, CI.
* Отрицательный контроль: оба сценария путей отклоняют исходную версию помощника.
* Тесты используют только временные локальные репозитории; реальные подмодули
  и их файлы не изменяются. Настройки Git пользователя в фикстуры не попадают.

Это отдельная проверка исправления инструмента сборки; полная сборка solution
после этой правки не заявляется. Игровой код и схема БД этой правкой не менялись;
ранее завершённый прогон 50/50 ниже относится к системе после её переноса.
